Laboratory scale wave tanks are reliable for initial steps in testing and validating computer vision algorithms related to wave dynamics. 

This output refines the Continuous Maximum Gradient (CMG) method to identify the wave surface location on a side view footage of a wave tank. This enables accurate estimation of the wave features which is necessary for testing vision and IMU based wave detection algorithms.


### Current scope
- Wave tank
- Vision-based feature identification
- Public release route for the supporting materials
